## Regression policy

Keep Native discovery enabled. Generated files must not be enumerated, statted, read or rendered during session discovery, manifest building or task loading. The report reader opens only explicitly configured project directories, after a user opens a report.

Measure stable and candidate builds on the same host using alternating requests. Compare shell, warm manifest, representative task structure and section latency separately. A running Codex may append to its rollout and invalidate the search cache; an unchanged snapshot is necessary for a meaningful cached-search comparison. HTTP measurements do not certify browser paint time.

Keep the 6.2.1 executable and review-state backup available throughout candidate validation. Rollback replaces the executable and restarts with the saved startup options; do not restore older review state over newer notes unless recovery requires it.
