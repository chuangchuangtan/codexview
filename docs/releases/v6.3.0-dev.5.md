## CodexView 6.3.0-dev.5 · Task window repair / 连续翻阅修复

Released 2026-10-25 (Asia/Shanghai). Development preview. Previous release files remain available.

- Prevent duplicate task mounting through one idempotent window commit.
- Update selection during ordinary scrolling without restarting navigation or cancelling prose requests.
- Restore measured task heights when replacing spacers; retain section measurements and paragraph anchors. Ignore stale prefetches and detached observers.
- Retry superseded payload requests; retain Important/Marked, notes, search and report navigation.

- 修复同一任务重复挂载，统一窗口增删逻辑。
- 普通滚动仅更新选中任务，不重启导航或取消正文请求。
- 恢复旧任务时保留实测高度与段落位置，忽略过期预加载和已移除节点的观察回调。
- 修复取消请求后的重新加载，保留审阅、笔记、搜索和报告阅读。

Validation: 30 Python tests, seven frontend suites, and real-server task 830–834 forward/backward/changing-direction checks. The reader stays bounded to three task DOM nodes. Native discovery remains enabled; source data stays strictly read-only. No session/index migration is required. Measurements and scope are in [performance notes](https://github.com/chuangchuangtan/codexview/blob/v6.3.0-dev.5/docs/performance.md).

验证包含实际大会话 830–834 前后及反复翻阅、不同高度、重复插入、迟到响应与阅读位置测试。正文保持最多三个任务节点，Native 发现开启，Codex 原始数据严格只读，无需重建索引。

### Install / 安装

Download [**codexview-6.3.0-dev.5**](https://github.com/chuangchuangtan/codexview/releases/download/v6.3.0-dev.5/codexview-6.3.0-dev.5). Back up review state and stop the service before replacing the executable. Run in the download directory / 备份审阅记录并停止旧服务，在下载目录执行：

```sh
mkdir -p "$HOME/.local/bin"
cp codexview-6.3.0-dev.5 "$HOME/.local/bin/codexview"
chmod +x "$HOME/.local/bin/codexview"
export PATH="$HOME/.local/bin:$PATH"
codexview --version
codexview serve --host 0.0.0.0 --port 80 --file-root /path/to/project
```

Restart with the same options and refresh the browser; verify `6.3.0-dev.5`. Container access uses the mapped host port. Local-only access: `codexview serve`.

用原参数启动并刷新浏览器，确认版本为 `6.3.0-dev.5`。容器从映射后的宿主机端口访问。
