## CodexView 6.2.1 · Public Preview / 公开预览版

A lightweight, read-only viewer for Codex CLI sessions. Single-file deployment on Linux and macOS; Python 3.7+ is required, with no third-party runtime dependencies.

轻量、只读的 Codex CLI 会话阅读器。支持 Linux 与 macOS，单文件部署，需要 Python 3.7+，无需第三方运行依赖。

### Highlights / 主要功能

- Native session discovery stays enabled; Codex-owned data remains read-only.
- On-demand reading for large conversations, task navigation, timestamps and expandable tool evidence.
- Content search, task-title filtering, private review marks and notes.
- Compact task navigator, resizable reading layout, dark/light themes and mobile drawer.

Native 会话发现始终开启；大会话按需加载，支持任务时间、正文搜索、执行记录、独立审阅笔记、紧凑侧栏、明暗主题与手机导航。

### Download and install / 下载与安装

Download **`codexview-6.2.1`**, then run these commands in the download directory:

下载无扩展名的 **`codexview-6.2.1`**，在下载目录执行：

```sh
mkdir -p "$HOME/.local/bin"
cp codexview-6.2.1 "$HOME/.local/bin/codexview"
chmod +x "$HOME/.local/bin/codexview"
export PATH="$HOME/.local/bin:$PATH"
codexview --version
```

For local access / 本机访问：

```sh
codexview serve
```

Open / 打开 http://127.0.0.1:17864/ .

For a server or container / 服务器或容器部署：

```sh
codexview serve --host 0.0.0.0 --port 80
```

Use the mapped host port when accessing a container. / 容器部署时使用映射后的宿主机端口访问。

### Preview limits / 预览版限制

First-time search of very large files can take several seconds and returns up to 200 matching records. This is a personal viewer without built-in login or multi-user access control; use a trusted network or authenticated proxy. Not every Codex CLI record format has been validated.

首次搜索大文件可能需要数秒，最多返回200条匹配记录。当前面向个人可信环境，不内置登录或多用户权限；公网访问需自行配置认证代理。尚未覆盖所有 Codex CLI 记录格式。
