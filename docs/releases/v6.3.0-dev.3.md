## CodexView 6.3.0-dev.3 · Development Preview / 开发预览版

Released 2026-10-21 (Asia/Shanghai). Linux/macOS, Python 3.7+, no third-party runtime dependencies. Previous 6.2.1 and 6.3.0-dev.2 files and baseline tags remain available.

2026-10-21（北京时间）发布。保持单文件、轻量与严格只读，保留旧版发布包及基线。这是开发预览版。

### Changes / 更新

- Continuous task scrolling retains evicted heights and preloads adjacent prose; asynchronous loading no longer seeks back to the task start.
- Sticky task context, visible-page new-content notifications and explicit Follow latest; manual reading pauses following.
- Section chunks inside exceptional tasks retain deep search and reading recovery.
- Optional compressed search cache: explicit build/update, cancellation, append support, bounded storage and streaming fallback; Chinese substrings preserved.
- Report links from loaded tasks, local image zoom, HTML image navigation and explicit parent/fork session links.

- 连续翻阅保留移出任务的高度并预加载邻接正文，移除异步加载后的回跳。
- 顶部任务上下文、新增内容提示、主动跟随最新；手动阅读暂停跟随。
- 超长单任务分块，保留深层搜索定位和阅读恢复。
- 可选压缩搜索缓存，主动构建、追加更新、可取消，保留中文子串与流式回退。
- 已读任务报告入口、图片放大、HTML 图片导航及明确元数据支持的会话关系。

On a 755-task / approximately 616 MB real session, 100-sample warm endpoint p95 values remained below 23 ms on server loopback. Three unique cache queries improved from 5.6–6.8 s to 2.8–3.7 s with identical results; explicit initial preparation took about 11 s. These are workload-specific HTTP/query measurements, not first-paint guarantees. See [performance scope](https://github.com/chuangchuangtan/codexview/blob/v6.3.0-dev.3/docs/performance.md).

### Install / 安装

Download [**codexview-6.3.0-dev.3**](https://github.com/chuangchuangtan/codexview/releases/download/v6.3.0-dev.3/codexview-6.3.0-dev.3). Back up review state and stop an existing service before replacing the executable.

下载上述单文件程序，在下载目录执行。已有安装请先备份审阅记录并停止服务。

```sh
mkdir -p "$HOME/.local/bin"
cp codexview-6.3.0-dev.3 "$HOME/.local/bin/codexview"
chmod +x "$HOME/.local/bin/codexview"
export PATH="$HOME/.local/bin:$PATH"
codexview --version
codexview serve --host 0.0.0.0 --port 80 --file-root /path/to/project
```

Expected version / 应显示：`CodexView 6.3.0-dev.3`.

For local-only access, run `codexview serve`. For containers, use the mapped host port. `--file-root` is a project directory, such as the session's `cwd`; file reading is disabled without it.

本机访问可用 `codexview serve`；容器使用映射后的宿主机端口。`--file-root` 指向项目工作目录，未指定时文件阅读关闭。

### Limits / 边界

Native discovery stays enabled. Codex-owned sessions, rollouts, config and auth are strictly read-only. Search cache preparation is optional and never runs on entry. Each cache is capped at 128 MiB, with two ready caches and at most one additional temporary build. Caches contain conversation text and require the same access protection as the viewer. Search returns at most 200 records. Reports and images retain configured roots and bounded reads. HTML scripts, forms and external resources remain blocked. Relationships without explicit metadata are not inferred. No built-in authentication or multi-user review isolation is provided.

Native 会话发现保持开启，Codex 原始数据严格只读。缓存需主动准备，每份最多 128 MiB，保留两份就绪缓存及最多一份临时构建。缓存含会话文本，应与阅读器采用相同访问保护。搜索最多 200 条，报告目录和体积限制不变，HTML 脚本与外部资源保持禁用，不猜测未声明的会话关系，不内置登录或多用户审阅隔离。
