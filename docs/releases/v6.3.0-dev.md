## CodexView 6.3.0-dev · Development Preview / 开发预览版

Released 2026-10-21 (Asia/Shanghai). Linux and macOS; Python 3.7+ with no third-party runtime dependencies. This is a preview, not a stable-release promotion. The 6.2.1 baseline remains available.

2026-10-21（北京时间）发布。支持 Linux 与 macOS，需要 Python 3.7+，无需第三方运行依赖。这是开发预览版，保留 6.2.1 历史基线。

### Changes / 更新内容

- Open linked Markdown and static HTML reports in a separate reader, on demand.
- Explicit read-only project roots, source view, manual refresh, and approved local images/CSS.
- Native discovery stays enabled; no report scans in the session opening path.

- 按需阅读会话链接中的 Markdown 和静态 HTML 报告。
- 支持指定项目目录、查看源码、手动刷新、本地图片与 CSS。
- Native 会话发现保持开启，报告读取不加入会话首屏索引。

This is the historical first document-reader preview. For reading recovery, report navigation fixes and Markdown contents, use [6.3.0-dev.2](https://github.com/chuangchuangtan/codexview/releases/tag/v6.3.0-dev.2).

这是最初的文档阅读预览版本。阅读位置恢复、报告导航修正与 Markdown 目录请使用 [6.3.0-dev.2](https://github.com/chuangchuangtan/codexview/releases/tag/v6.3.0-dev.2)。

### Install / 安装

Download [**codexview-6.3.0-dev**](https://github.com/chuangchuangtan/codexview/releases/download/v6.3.0-dev/codexview-6.3.0-dev), then run these commands in the download directory.

下载上述无扩展名单文件程序，在下载目录依次执行。已有安装请先停止服务并备份审阅记录。

```sh
mkdir -p "$HOME/.local/bin"
cp codexview-6.3.0-dev "$HOME/.local/bin/codexview"
chmod +x "$HOME/.local/bin/codexview"
export PATH="$HOME/.local/bin:$PATH"
codexview --version
```

Expected / 应显示：`CodexView 6.3.0-dev`.

For a server or container / 服务器或容器部署：

```sh
codexview serve --host 0.0.0.0 --port 80 --file-root /path/to/project
```

`--file-root` is the project working directory on the server, such as the session’s `cwd`, not the `.codex/sessions` storage directory. Repeat it for additional roots. File reading stays disabled without an explicit root. Use the mapped host port for container access.

`--file-root` 指向服务器上的项目工作目录，可与会话的 `cwd` 一致，不是 `.codex/sessions` 数据目录。可重复设置多个目录；未指定时文件阅读关闭。容器访问使用映射后的宿主机端口。

For local access / 本机访问：`codexview serve`, then open / 打开 http://127.0.0.1:17864/ .

### Files and limits / 文件与边界

- `codexview-6.3.0-dev`: standalone program / 单文件程序。
- ZIP / tar.gz: matching source, documentation and tests / 对应版本的源码、文档与测试。
- Manifest / SHA256SUMS: source and download verification / 源码与下载校验。

HTML previews disable scripts, forms and external resources. Reports stay within configured roots and are read-only. There is no built-in login; use a trusted network or authenticated proxy. First search of a large session can take seconds; at most 200 matches are returned. Windows and all Codex CLI formats have not been validated.

HTML 预览禁用脚本、表单和外部资源，报告仅在配置目录内只读访问。不内置登录，远程访问请使用可信网络或认证代理。首次搜索大会话可能需要数秒，最多返回 200 条匹配。Windows 与全部 Codex CLI 格式尚未完成验证。
