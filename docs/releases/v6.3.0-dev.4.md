## CodexView 6.3.0-dev.4 · Review controls hotfix / 审阅操作修复

Released 2026-10-22 (Asia/Shanghai). Development preview; Linux/macOS, Python 3.7+, no third-party runtime dependencies. Previous release files remain available.

### Fixed / 修复

- Important, Marked, Later, Reviewed and note edits now reach the existing review-state API. The missing frontend save handler previously caused clicks to fail before sending a request.
- Restore next/previous buttons, J/K and command-palette task navigation.
- Update review controls, navigator badges and counts without reloading prose or moving the reading position. Serialize writes and disable duplicate pending toggles.
- Failed saves show a message and retain unsaved note text; failed marks are not displayed as saved.
- Add regressions covering actual clicks, keyboard actions, all review flags, notes, persistence, errors, filtering and source integrity.

- 恢复 Important、Marked、Later、Reviewed 和笔记保存：此前缺失前端保存函数，点击后未发出请求。
- 恢复上下任务按钮、J/K 与命令面板导航。
- 原位更新按钮、左侧标记及统计，保留正文和阅读位置；保存请求串行处理，避免重复点击。
- 保存失败明确提示，保留未保存笔记，不把失败标记显示为已保存。
- 补充实际点击、快捷键、全部标记、笔记、持久化、失败、筛选及源文件完整性测试。

Includes the continuous reader from 6.3.0-dev.3. Native discovery remains enabled. Codex-owned sessions, rollouts, config and auth stay strictly read-only; only CodexView review state is written. No index rebuild or transcript-format change is required.

保留 6.3.0-dev.3 连续阅读能力。Native 发现保持开启；Codex 原始 session、rollout、config、auth 严格只读，仅写入 CodexView 自己的审阅状态，无需重建索引或迁移会话。

### Install / 安装

Download [**codexview-6.3.0-dev.4**](https://github.com/chuangchuangtan/codexview/releases/download/v6.3.0-dev.4/codexview-6.3.0-dev.4). Back up review state and stop an existing service before replacing the program. Run in the download directory / 先备份审阅记录并停止旧服务，在下载目录执行：

```sh
mkdir -p "$HOME/.local/bin"
cp codexview-6.3.0-dev.4 "$HOME/.local/bin/codexview"
chmod +x "$HOME/.local/bin/codexview"
export PATH="$HOME/.local/bin:$PATH"
codexview --version
codexview serve --host 0.0.0.0 --port 80 --file-root /path/to/project
```

Expected / 应显示：`CodexView 6.3.0-dev.4`. Restart with your previous options. Container access uses the mapped host port; refresh the browser to load the fixed controls.

使用原参数重新启动；容器从映射后的宿主机端口访问，浏览器刷新后加载修复。
